# 飞书激活审批单 · 逐步建单指南

> 给「数字员工激活申请」审批单的从零创建步骤，精确到菜单/按钮/控件。
> 配套：[飞书人工流转 SOP](./activation-feishu-manual-sop.md)。
> 人工流转方案：审批单**只给人填看，不接任何 API**，所以无需关心审批 code / 字段 id。

---

## 前置

- 你需要是飞书企业的**管理员**或有「审批」应用的创建权限。
- 用电脑浏览器操作最顺（手机 App 也能建，但字段配置在电脑端更清楚）。

---

## 第 1 步 · 打开审批管理后台

二选一：

- **入口 A**：飞书客户端 → 左侧/底部「工作台」→ 搜索并打开「审批」→ 右上角头像旁「**审批后台**」或「管理后台」。
- **入口 B**（推荐，直达）：浏览器打开 `https://www.feishu.cn/approval/admin`，用企业账号登录。

进去后左侧能看到「**审批列表 / 我创建的审批 / 创建审批**」。

---

## 第 2 步 · 创建审批

1. 点右上角「**+ 创建审批**」（或「新建审批」）。
2. 若让你选模板：选「**自定义创建 / 空白创建**」（不要用请假/报销等现成模板）。
3. 基础信息：
   - 审批名称：`数字员工激活申请`
   - 图标 / 分组：随意（分组可放「IT / 运维」之类）。
4. 进入「**表单设计**」页（核心，下一步）。

---

## 第 3 步 · 设计表单字段（最关键）

在表单设计页，左侧是「控件库」，中间是表单画布。**拖控件到画布**，按下表配置：

### 字段 1：设备码
1. 从控件库拖一个「**单行文本**」到画布。
2. 点中它，右侧属性：
   - 标题：`设备码`
   - 是否必填：**是**
   - 提示文字（可选）：`填入目标机 deploy 显示的序列号，如 3E56-77F8-E917-9E20-7A30`

### 字段 2：到期日期（申请人选）
1. 从控件库拖一个「**日期**」控件到画布（控件库里叫「日期」/「日期时间」，选「日期」即可）。
2. 标题：`到期日期`，必填：**是**。
3. 格式选「年-月-日」（`YYYY-MM-DD`）。
4. 提示文字（可选）：`选择激活码到期日，如 2027-06-01`

   > 申请人直接选哪天到期，灵活不受档位限制。管理员出码时把这个日期原样传给
   > 接口的 `expires`（`/license/issue` 支持 `YYYY-MM-DD`）。

### 字段 3：机器备注 / 客户（可选但建议，便于台账）
1. 再拖一个「**单行文本**」。
2. 标题：`机器备注/客户`，必填：否。

### 字段 4：授权码（管理员回填）
1. 拖一个「**多行文本**」（**不要用单行**——授权码是一长串 base64，单行框显示不下）。
2. 标题：`授权码`
3. 必填：**否**（发起时为空，管理员审批时再填）。
4. 提示文字（可选）：`由管理员出码后填入；申请人请留空`

> 控件名称在不同版本可能叫「单行输入框 / 多行输入框」或「文本 / 多行文本」，认准
> 「一行」vs「多行」即可。

---

## 第 4 步 · 设置审批流程

切到「**流程设计**」页：

1. 默认会有「发起人」节点。
2. 加一个「**审批人**」节点：
   - 审批人设为 **持私钥、能在 216 出码的管理员**（你本人或指定运维）。
   - 这样「审批的人」＝「出码并回填授权码的人」，一步到位最省事。
3. 不需要抄送、不需要条件分支（人工流转，保持最简）。

---

## 第 5 步 · 发布

1. 右上角「**发布**」。
2. 设置可见范围 / 谁能发起：选「**全员**」或限定到装机员所在部门。
3. 确认发布。

发布后，装机员在飞书「工作台 →（你的分组）→ 数字员工激活申请」即可发起。

---

## 配好后 · 一次走查（验证建对了）

自己发起一单测试：

1. 工作台找到「数字员工激活申请」→ 发起。
2. 「设备码」填一个测试值（如 `TEST-0000`），提交。
3. 你作为审批人收到 → 打开单子，确认能看到「设备码」、能在「授权码」多行框里**填入并保存**。
4. 填一段长文本进「授权码」确认显示完整（验证多行控件没问题）。
5. 批准 / 撤回该测试单。

走查通过即配置正确。

---

## 与整条激活流程的衔接

| 谁 | 在飞书做什么 | 对应 |
|----|--------------|------|
| 装机员 | 发起单，填「设备码」+ 选「到期日期」 | deviceCode + 到期日（YYYY-MM-DD） |
| 管理员 | 按设备码 + 到期日在 216 出码 → 授权码填进「授权码」字段 → 批准 | `curl /license/issue`，`expires=<到期日>`（见 [部署文档](./license-issuer-server-deploy.md)） |
| 装机员 | 在单子看到「授权码」→ 复制 → 放目标机 | deploy 双通道注入 → 激活 |

> 全程人工，飞书只是传话筒 + 台账，不接代码。
