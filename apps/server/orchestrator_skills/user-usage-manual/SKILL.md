# 用户使用手册

数字员工客户端（Digital Employee Client）使用指南。本文档帮助你了解和使用客户端的全部功能。

## 一、快速入门

### 登录应用

1. 启动应用后，进入登录页面
2. 输入**用户名**和**密码**，可选择勾选"记住我"持久化登录状态
3. 点击**登录**按钮，加载成功后进入主界面
4. 如果忘记密码，可在登录页底部点击注册链接进入注册页
5. 支持**飞书 SSO 登录**，点击"飞书登录"按钮通过 OAuth 授权登录
6. 首次登录会弹出**欢迎引导**，可选择跟随交互式引导教程或跳过

### 首次引导

欢迎引导包含 5 个步骤：招募员工 → 查看联系人与聊天 → 编辑员工配置派遣任务 → 查看任务通知 → 设置入口。引导完成后随时可在"设置 → 通用"中重新触发。

### 主界面布局

│  └────────┘  │                                      │  └─────────┘ │
│              │                                      │              │

- **左侧工具栏**：切换联系人、技能管理、日历、工作台
- **中间聊天区**：对话列表 + 消息内容 + 输入框
- **右侧面板**：通知中心、制品文件、工作台仪表盘

## 二、与 AI 员工聊天

### 选择对话对象

在左侧联系人面板中选择对话对象：

| 类型 | 图标 | 说明 |
|------|------|------|
| **总管** | 环形头像 | 总管理员，可调度所有员工完成任务 |
| **员工** | 头像+在线状态 | 单个 AI 员工，各有专长和技能 |
| **群组** | 群组图标 | 多员工参与的群聊 |

最近联系人列表可以折叠为仅图标模式。

### 发送消息

1. 选中联系人，在底部输入框输入文字
2. 按 **Enter** 发送消息
3. AI 回复会以**流式（SSE）** 逐字展示，无需等待完整回复

### 高级输入功能

| 功能 | 操作 | 说明 |
|------|------|------|
| **斜杠命令** | 输入 `/` | 触发该员工可用技能列表 |
| **@ 提及** | 输入 `@` | 在群组/总管对话中提及特定员工 |
| **上传文件** | 点击附件按钮 | 上传文件到对话中供 AI 分析 |
| **停止生成** | 点击停止按钮 | 中断 AI 正在生成的回复 |

### 会话管理

- 与每个联系人的对话按时间排列在中间面板
- 未读消息在联系人和对话上显示数字角标
- 对话支持自动滚动到最新消息
- 代码块在消息中高亮显示

## 三、招募新员工

### 入口

点击工具栏中的"招募"按钮，或在联系人面板点击"添加"。

### 操作步骤

1. **描述需求**：在文本框中输入你对员工的要求，如"需要一个数据分析师，擅长 Python 和 SQL"
2. **选择模板**：也可以直接点击热门口模版快速填充：
   - 数据分析师 / 运维工程师 / 测试工程师
   - 内容运营 / HR 助手 / 财务助手 / 行政助理
3. **查看候选人**：系统生成多名候选人，每张卡片显示：
   - 员工名称和能力描述
   - **匹配度评分**
   - 拥有的 MCP 工具和技能
4. **录用配置**：选择满意的候选人后，配置：
   - MCP 工具能力（从可用列表中选择）
   - 技能（从可用列表中选择，可多选）
   - 排班时间（日期范围、时段、备注）
   - 定时任务（cron 表达式调度）

### 管理员工

- 在联系人面板右键或点击员工查看详情
- 可编辑员工配置、查看技能和任务
- 可删除不再需要的员工

## 四、技能管理

### 入口

点击左侧工具栏的**技能**标签页。

### 查看已安装技能

- 展示所有已安装的技能卡片（网格布局）
- 每张卡片显示：英文名、中文名、来源（本地/内置）
- 超过 6 个技能时显示"展开更多"按钮
- 可搜索技能

### 安装新技能

| 方式 | 操作 |
|------|------|
| **远程市场** | 浏览远程技能库，按分类筛选，点击"安装"按钮 |
| **ZIP 导入** | 点击"导入 ZIP"，选择本地的 `.zip` 技能包 |
| **从制品导入** | 在制品面板中，将草稿技能提升为正式技能 |

安装冲突时系统会提示覆盖确认。

### 查看技能详情

点击技能卡片查看：
- 技能 ID（目录名）、中文名称、导入时间
- 文件列表和 `SKILL.md` 内容（只读）
- 远程技能显示名称、描述、完整提示词

## 五、工作台仪表盘

### 入口

点击左侧工具栏的**工作台**标签页。

### 功能概要

| 区域 | 内容 |
|------|------|
| **左侧面板（320px）** | 业绩指标卡片（月结余、GDP、排名）、排班月历、今日任务列表 |
| **主区域** | 可拖拽自定义的 Widget 网格，添加技能查询 Widget |
| **右侧面板** | 员工监控面板（月历、任务总计、执行详情） |

### 自定义工作台

1. 点击"添加区块"按钮
2. 选择需要显示的技能 Widget
3. 拖拽调整位置和大小
4. 可随时关闭不需要的区块

### 查看任务执行

- **今日任务列表**：显示所有已执行的定时任务
- **状态标记**：运行中（蓝色）/ 成功（绿色）/ 失败（红色）/ 超时（橙色）/ 卡住（紫色）/ 待处理（琥珀色）
- **执行详情**：点击单条任务查看完整执行日志

## 六、排班与任务

### 入口

点击左侧工具栏的**日历**标签页。

### 排班月历

- 月历视图，每日格子显示已排班员工
- 切换上/下月导航
- 点击日期可查看该日排班详情

### 创建排班

1. 点击排班编辑按钮
2. 选择员工、日期范围、班次时段
3. 填写备注说明
4. 保存后即生效

### 定时任务

员工 `meta_json.tasks` 中定义的定时任务会通过 `TaskService.sync_workspace_tasks()` 同步到调度器。

- 调度器运行在后台（APScheduler BackgroundScheduler，CST 时区）
- 仅执行 `dispatch_type == "skill"` 的任务
- 支持**确认流程**：从 SKILL.md 解析 `confirm_url`，执行后写入确认记录
- 修改员工任务后需等待调度器 reload（或手动触发）

## 七、制品与文件管理

### 入口

聊天界面右侧的**制品面板**。

### 浏览文件

- 树形结构展示三类文件：
  - **制品**：AI 生成的代码和文档
  - **上传**：用户上传的附件
  - **技能草稿**：待导入的技能文件
- 支持查看代码（语法高亮）、文本、图片、表格、文档

### 文件操作

| 操作 | 说明 |
|------|------|
| 查看内容 | 点击文件自动渲染 |
| 下载 | 右键或点击下载按钮 |
| 删除 | 右键或点击删除按钮 |
| 复制内容 | 右键菜单选择复制 |
| 导入为技能 | 对技能草稿文件，点击"导入为技能" |
| 刷新列表 | 点击刷新按钮 |

## 八、通知中心

### 入口

工具栏的**铃铛图标**。

### 通知类型

| 类型 | 说明 | 颜色标记 |
|------|------|---------|
| 任务完成 | 定时任务执行成功 | 绿色 |
| 任务失败 | 定时任务执行出错 | 红色 |
| 任务超时 | 执行超过时限 | 橙色 |
| 任务卡住 | 执行过程中卡住 | 紫色 |
| 任务运行中 | 任务正在执行 | 蓝色 |

### 操作

- 点击单条通知查看详情
- **标记已读** / **全部已读**
- 通知弹出对话框可在设置中关闭
- 支持 OS 桌面通知（可在设置中开关）
- 任务完成时 Electron 托盘图标会闪烁

## 九、桌面宠物

### 入口

设置 → 宠物标签页。

### 功能

- **透明无框**独立窗口，始终置顶，显示在桌面右下角
- 角色动画：待机、跑步、挥手、跳跃、等待、失败等多种状态
- **语音输入**：点击宠物开始录音，再次点击停止并发送到总管
- **拖拽移动**：按住宠物拖拽到任意位置
- **双击**：触发行走动画

### 设置选项

| 选项 | 说明 |
|------|------|
| 启用/禁用 | 开关宠物窗口 |
| 皮肤选择 | 内置皮肤（默认 "eve"）和自定义皮肤 |
| 显示策略 | 始终显示 / 主窗口最小化时显示 |
| 置顶 | 是否始终保持在其他窗口之上 |

自定义皮肤从 `~/.codex/pets/` 目录加载，支持 `petdex://` 协议。

### 语音气泡状态

| 场景 | 显示文字 |
|------|---------|
| 待机 | — |
| 录音中 | "录音中，再点结束" |
| 识别中 | "识别并发送给总管…" |
| 提示 | "点击说话，再点结束并发送" |

## 十、设置

### 入口

工具栏的**齿轮图标**，或系统托盘右键菜单"打开设置"。

### 设置标签

| 标签页 | 功能 |
|--------|------|
| **账户** | 查看个人信息（头像/姓名/部门/用户名/手机/邮箱）、修改密码、退出登录、注销账户（已禁用） |
| **通用** | 主题切换（浅色/深色/跟随系统）、开机自启、自动更新、桌面通知、重新引导 |
| **快捷键** | 查看键盘快捷键参考列表 |
| **模型** | 配置 AI 模型名称、API Key、API 地址、最大输入 Token（高级选项） |
| **宠物** | 桌面宠物设置（见第九章） |
| **扩展** | 插件管理（见第十一章） |
| **关于** | 应用版本号、构建时间、版权信息、检查更新按钮 |

## 十一、扩展管理

### 入口

设置 → 扩展标签页。

### 查看已安装扩展

列表展示每个扩展的 ID、版本号、UI/服务类型指示器。

### 操作

| 操作 | 说明 |
|------|------|
| 启用/禁用 | 开关切换，禁用后扩展服务会停止 |
| 打开界面 | 有 UI 的扩展可打开独立窗口 |
| 安装 ZIP | 点击"安装扩展"，选择本地的 `.zip` 扩展包 |
| 卸载 | 确认后删除扩展文件 |
| 发送测试事件 | 调试模式下发送 host event 到扩展 |
| 刷新列表 | 点击刷新按钮 |

### 扩展文件位置

手动安装的扩展位于 `~/.digital-employee/extensions/<扩展ID>/`。
每个扩展必须包含 `digital-employee.extension.json` 清单文件。

## 十二、系统托盘（Electron 桌面版）

### 入口

系统托盘图标（任务栏右侧）。

### 右键菜单

| 菜单项 | 说明 |
|--------|------|
| 显示窗口 | 将主窗口带到前台 |
| 打开设置 | 直接打开设置页面 |
| 重启应用 | 重启整个应用（含 Python 后端） |
| 退出 | 完全退出应用 |

### 其他操作

- **双击托盘图标**：快速恢复主窗口
- **通知闪烁**：任务执行完成时托盘图标闪烁，点击窗口后停止
- **关闭主窗口**：默认最小化到托盘，不退出应用

## 十三、常见问题

### 无法登录

| 可能原因 | 解决方法 |
|---------|---------|
| 账号密码错误 | 检查用户名和密码是否正确 |
| 后端未启动 | 检查右下角或日志，确认后端服务是否运行 |
| 网络不通 | 检查登录页右上角的服务器端配置，确认 IP/端口正确 |
| 密码过期 | 系统会提示"密码已过期"，需修改密码后登录 |

### 聊天没有回复

| 可能原因 | 解决方法 |
|---------|---------|
| AI 模型未配置 | 前往"设置 → 模型"检查 API Key 和模型名称 |
| 员工没有技能 | 为该员工安装至少一个技能 |
| 后端服务异常 | 查看 `~/.digital-employee/logs/app.log` |

### 技能不显示或不工作

1. 检查技能是否已安装（技能标签页查看）
2. 远程安装的技能是否来源可用
3. ZIP 导入的技能格式是否正确（需包含 `SKILL.md`）
4. 查看应用日志是否有错误提示

### 定时任务未执行

1. 检查员工排班是否已配置
2. 确认任务的 `dispatch_type` 为 `"skill"`
3. 检查 SKILL.md 中 cron 表达式是否正确
4. 修改配置后需等待调度器刷新（或重启应用）
5. 查看任务执行日志了解失败原因

### 桌面宠物不显示

1. 前往"设置 → 宠物"确认已启用
2. 检查显示策略设置
3. 尝试重启应用

### 扩展插件不工作

1. 确认已启用（设置 → 扩展 → 开关打开）
2. 检查 ZIP 包包含 `digital-employee.extension.json`
3. 查看是否有版本兼容问题
4. 尝试重新安装

### 应用无法更新

1. 检查"设置 → 通用"中自动更新是否开启
2. 确认服务器端配置了正确的更新包地址
3. Windows 更新格式为 `.exe`，macOS 需要同时包含 `.dmg` 和 `.zip` + `latest-mac.yml`

### 如何获取帮助

- 查看 `~/.digital-employee/logs/` 下的日志文件
- 与当前员工对话询问使用问题

## 十四、数据与存储

### 数据位置

| 数据 | 路径 |
|------|------|
| SQLite 数据库 | `~/.digital-employee/data/app.db` |
| 登录凭证 | `~/.digital-employee/auth.json` |
| 用户设置 | `~/.digital-employee/settings.json` |
| 日志文件 | `~/.digital-employee/logs/` |
| 本地员工技能 | `apps/server/local-employees/` |
| 扩展插件 | `~/.digital-employee/extensions/` |
| 自定义宠物皮肤 | `~/.codex/pets/` |

### 清除数据

删除上述路径即可重置对应数据。注意：删除数据库将清除所有员工、对话和任务数据。
